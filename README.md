📊 MarkInsight — Student Performance Analyzer

«Turning student marks into simple, meaningful insights.»

🚀 About the Project

MarkInsight is a beginner-friendly Python Data Science project that analyzes student academic performance.

Instead of just displaying marks, the program calculates useful statistics and presents the results visually through a bar chart.

✨ What It Does

- 👩‍🎓 Stores student subject marks
- 🧮 Calculates total marks
- 📈 Calculates individual averages
- 🏆 Identifies the highest scorer
- 📉 Identifies the lowest scorer
- 📚 Calculates the overall class average
- 📊 Generates a visual comparison of student performance

🛠️ Built With

Technology| Purpose
🐍 Python| Core programming
🐼 Pandas| Data processing
📊 Matplotlib| Data visualization
